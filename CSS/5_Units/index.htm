Types of Units -

  • Absolute Units - Unit which are fixed and does not change with screen size -
    1. Pixel - px
    2. Centimeter - cm
    3. Milimeter - mm
    4. Inches - in
    5. Points(1/72 of an inch) - pt
  • Relative Units - It is responsive and scale based on parent element -
    1. persent of parent - %
    2. relative to parent - em
    3. relative to root element(HTML) - rem
    4. viewport width - vw
    5. viewport height - vh
    6. smaller viewport dimension(height in case of pc) - vmin
    7. larger viewport dimension(width is case of pc) - vbmax
  • calc() function will calculate given dimension - cal(100% - 20px)
